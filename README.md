# LayerLab — сайт 3D-печати

Статический адаптивный сайт на HTML/CSS/JavaScript, с локальным просмотром и приблизительным анализом STL / OBJ / 3MF. Внешние каталоги моделей доступны как прямые поисковые ссылки. Отправка заказа и выбранного файла в Telegram выполняется через отдельный Cloudflare Worker; токен Telegram-бота хранится только на сервере.

## 1. Локальный запуск сайта

1. Распакуйте архив целиком.
2. Откройте `index.html` в браузере. Для более реалистичного тестирования используйте локальный HTTP-сервер (например, расширение Live Server в VS Code), поскольку некоторые браузерные функции могут ограничиваться при открытии через `file://`.
3. Папка `assets/` должна лежать рядом с `index.html`.

## 2. Поиск 3D-моделей

В блоке заказа доступны прямые поисковые ссылки на Thingiverse, Printables, Cults3D, MyMiniFactory и MakerWorld. Для поддерживаемых площадок текст запроса автоматически добавляется к ссылке. Поиск не парсит сайты и не обещает единую выдачу. После выбора модели скачайте разрешённый файл, вставьте ссылку на страницу модели (по желанию) и приложите STL / 3MF / OBJ к заказу.

## 3. Настроить Telegram-бота, чтобы файл действительно приходил

**Пока не заполнен адрес Worker, форма не отправляет заказ.** Это намеренно: никакой токен нельзя безопасно поместить в HTML/JavaScript. После описанной ниже настройки сайт отправляет сам файл и детали заявки в ваш Telegram-чат через бота. Вручную прикреплять файл больше не нужно.

### A. Создать бота

1. В Telegram откройте `@BotFather` и выполните `/newbot`.
2. Придумайте имя и username бота. BotFather выдаст токен. Не публикуйте его, не отправляйте в чат с кодом и не вставляйте в `index.html`.
3. Откройте только что созданного бота и отправьте ему `/start`.
4. Получите ID своего чата с ботом: откройте в браузере адрес `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`, подставив токен локально. В ответе найдите `message.chat.id`. Не публикуйте полный URL, так как он содержит токен.

### B. Развернуть Worker в Cloudflare

Подойдёт бесплатный Cloudflare Workers для приёма файлов размером до 30 МБ из текущей формы. В Bot API Telegram метод `sendDocument` поддерживает файлы до 50 МБ; фактический предел формы оставлен 30 МБ.

1. Откройте Cloudflare Dashboard → **Workers & Pages** → **Create** → **Create Worker**.
2. Создайте Worker, например `layerlab-order-bot`, откройте его редактор и замените пример кода содержимым файла `worker/src/index.js`.
3. В настройках Worker → **Settings → Variables and Secrets** добавьте:
   - `TELEGRAM_BOT_TOKEN` — Secret, токен от BotFather;
   - `TELEGRAM_CHAT_ID` — Secret, ID из шага A;
   - `ALLOWED_ORIGINS` — обычную переменную со списком разрешённых origin через запятую. Например, `https://YOUR-USERNAME.github.io`. В origin не добавляйте `/repo-name` и не ставьте завершающий `/`. При локальном тестировании можно временно добавить `http://localhost:5500`.
4. Сохраните изменения и опубликуйте Worker. Его URL будет примерно `https://layerlab-order-bot.<ваш-аккаунт>.workers.dev`.
5. Проверьте `https://<ваш-worker>.workers.dev/health`: должно быть `{"ok":true,"configured":true}`. Этот endpoint не раскрывает токен или ID чата.

> При использовании другого домена сайта добавьте именно origin этого домена в `ALLOWED_ORIGINS`. Если origin отсутствует в allowlist, Worker отклонит запрос.

### C. Подключить сайт к Worker

Откройте `assets/config.js` и вставьте полный URL API, например:

```js
window.LAYERLAB_CONFIG = {
  orderApiUrl: "https://layerlab-order-bot.<ваш-аккаунт>.workers.dev/api/order"
};
```

Сохраните файл и снова загрузите изменения на GitHub Pages / выбранный статический хостинг. Значение в `config.js` — только публичный адрес API; секреты сюда не добавлять.

### D. Как выглядит отправка

- Если выбрали STL / 3MF / OBJ, Worker отправляет файл в чат бота через `sendDocument`, а затем отправляет аккуратно оформленную сводку с тем же номером заказа.
- Если файла нет, но есть описание или ссылка на модель, бот получает сводку заявки без вложения.
- В Telegram приходят имя, контакты для ответа, материал, цвет, количество, способ получения, ссылка на модель, комментарий, приблизительная оценка и имеющиеся метрики анализа.
- Если Telegram принял файл, но не принял полное сообщение с деталями, сайт покажет отдельный статус частичной отправки; основные поля также включаются в подпись к файлу.

## 4. Что работает

- Адаптивная главная страница, RU / EN, анимации, галерея и раздел «О мастерской».
- Внешний поиск моделей через Thingiverse, Printables, Cults3D, MyMiniFactory и MakerWorld.
- Загрузка STL / 3MF / OBJ до 30 МБ и локальный анализ геометрии в браузере.
- Предварительная оценка расхода пластика, времени и диапазона цены.
- Отправка файла вместе с заявкой в Telegram-бот после настройки Worker.

## 5. Ограничения перед публичным запуском

- **Наценка ещё не защищена.** Расчёт предварительной цены пока выполняется в браузере. Интерфейс не показывает наценку отдельно, но внимательный пользователь может исследовать клиентский JavaScript. Для конфиденциального ценообразования нужно перенести расчёт в Worker.
- **Расценки в `assets/model-tools.js` тестовые.** Перед публичным запуском замените их на реальные закупочные цены пластика и утверждённые правила цены. Не используйте тестовый диапазон как финальное коммерческое предложение.
- **Анализ не равен нарезке слайсером.** Точное время и расход пластика зависят от профиля принтера, количества стенок, верхних / нижних слоёв, ориентации и поддержек. Подтверждайте заказ вручную.
- **3MF может содержать сложные сборки.** Проверьте сложные или повреждённые модели в слайсере.
- **Лицензии сторонних моделей.** Перед коммерческой печатью проверьте лицензию выбранного файла. Сайт только открывает каталоги и не копирует их модели.
- После настройки Worker загруженный файл пересылается в Telegram и может быть доступен участникам указанного чата. Не отправляйте данные и модели, которые не должны туда попадать.
- Оплата, учёт заказов, личные кабинеты и админ-панель пока не подключены.

## 6. Полезные файлы

- `index.html` — страницы и интерфейс.
- `assets/figurine-cat.webp`, `assets/figurine-sculpture.webp`, `assets/functional-part.webp` — существующие изображения, сохранены.
- `assets/model-tools.js` — анализ геометрии, визуализация и приблизительная оценка.
- `assets/config.js` — публичный URL Worker; бот-токена здесь нет.
- `worker/src/index.js` — серверный код, который проверяет заказ и отправляет файлы / сводку Telegram-боту.
- `worker/wrangler.toml` — пример конфигурации для развёртывания через Wrangler CLI; для Dashboard можно настроить переменные вручную.
